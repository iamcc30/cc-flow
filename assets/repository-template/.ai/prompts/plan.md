# Plan 阶段提示模板

将 `{{TASK_PATH}}` 替换为实际任务路径后使用。

```text
你现在处于 PLAN 阶段。请先阅读 AGENTS.md、.ai/conventions.md、项目上下文文件，以及 {{TASK_PATH}}/task.md。

只进行只读调查，不修改产品代码。把计划写入 {{TASK_PATH}}/plan.md，并确保包含：
1. 对目标、非目标和验收标准的复述；
2. 当前实现与相关约束；缺陷任务需说明根因及证据；
3. 方案、关键取舍和被放弃的方案；
4. 预计修改的文件/模块及每项原因；
5. 业务、接口、数据、兼容性、安全、性能和运维影响；
6. 分层测试计划；
7. 风险、缓解措施和可执行回滚方案；
8. 未知项、假设和需要确认的问题。

计划完成后，将 task.md 的 status 更新为 PLANNED。若任务需要人工批准，停止实现并请求确认；不得提前修改产品代码。
```
