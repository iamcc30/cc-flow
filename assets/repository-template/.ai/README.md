# `.ai` 工作区说明

`.ai/` 保存 AI 与人类共同使用的项目事实、研发约束和任务证据。它是版本库的一部分，不是聊天记录归档，也不是秘密信息存储区。

## 文件职责

- `project.md`：产品目标、范围、用户、成功指标和非目标。
- `architecture.md`：系统边界、模块、依赖、数据、接口和部署约束。
- `business.md`：统一术语、业务规则、状态机、权限和异常流程。
- `conventions.md`：AI 必须遵守的研发协议与完成标准。
- `decisions.md`：需要长期保留的架构或业务决策。
- `progress.md`：当前阶段、已完成事项、风险和下一步。
- `prompts/`：Plan、Implement、Test、Review 阶段的可复用提示模板。
- `templates/`：任务材料的空白模板。
- `tasks/`：实际任务记录，每个任务一个目录。

## 维护原则

1. 只记录可验证、会复用的事实。
2. 行为发生变化时，同一个任务内同步文档。
3. 决策写清背景、选项、取舍和后果，不只写结论。
4. 进度文件保持简短，详细证据放在任务目录。
5. 不记录密码、令牌、私钥、个人敏感信息或生产数据。
6. 过时内容应明确替换或标记，而不是静默叠加冲突信息。
