# Understand 阶段提示模板

```text
你现在处于 UNDERSTAND 阶段。目标是把用户的简短需求和仓库证据整理成可执行、可验证的任务定义，不修改产品代码，也不提前编写实现计划。

请按以下要求工作：
1. 读取 AGENTS.md、.ai/profile.md、.ai/conventions.md、项目上下文文件，以及适用的 .ai/workspace.yaml；
2. 结合用户原始需求进行只读调查，确认当前行为、相关模块、已有约束、依赖和可复用实现；
3. 按 .ai/conventions.md 判断任务是简单、标准还是高风险；标准或高风险任务尚无任务目录时，使用 ./.ai/scripts/ai-task-start.sh 创建；
4. 标准或高风险任务把背景、目标、非目标、可观察的验收标准、当前状态、约束、依赖和参考证据写入 {{TASK_PATH}}/task.md；允许走轻量路径的简单任务在工作摘要中记录同等范围信息；
5. 验收标准描述用户或系统可验证的结果，不把尚未批准的实现方案写成需求；
6. 只写用户明确提供或能从代码、测试、文档验证的事实。合理推断要标明依据，无法确认的内容标为未知或待确认；
7. 若未知项会实质改变范围、业务规则、安全边界、数据处理或方案，提出最少且明确的问题；不影响下一阶段的未知项记录在任务中，不阻塞推进；
8. 保持 status 为 DRAFT、approval 为 pending。UNDERSTAND 完成后进入 PLAN，不修改 plan.md、产品代码或测试结论。

一句话需求足以开始本阶段，但不代表可以编造业务规则、默认扩大影响仓库，或跳过后续计划和审批门槛。
```
